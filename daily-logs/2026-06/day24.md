### 2. 系统设计 1：AI Agent 构建平台（70min）
#### 2.1 需求澄清（10min）
- 目标用户：开发者 / 非技术用户
- 核心功能：Agent 编排（拖拽式）+ 知识库 + 插件市场 + 调试/评估
- 规模：先支持 1000 个并发 Agent 会话

#### 2.2 架构设计（30min）
```
┌──────────────────────────────────────────────┐
│                  前端 (React)                  │
│    工作流编辑器 │ Agent 管理 │ 调试面板          │
├──────────────────────────────────────────────┤
│              API Gateway (Kong/APISIX)         │
├────────────┬────────────┬─────────────────────┤
│  Agent 引擎 │  知识库服务 │  插件/Tool 管理器    │
│ (LangGraph) │ (ChromaDB) │  (MCP Server 集群)  │
├────────────┴────────────┴─────────────────────┤
│         模型网关 (路由/限流/降级/缓存)           │
│     GPT-4o │ Claude │ Qwen │ DeepSeek         │
├──────────────────────────────────────────────┤
│     消息队列 (RabbitMQ/Kafka) │ 数据库 (PG)     │
│     Redis (Session State + Cache)              │
└──────────────────────────────────────────────┘
```
- [ ] 画出完整架构图
- [ ] 标注每层的技术选型和理由

#### 2.3 核心模块深挖（20min）
**Agent 引擎**：
- 工作流如何定义与存储？（JSON DSL / YAML）
- 如何支持条件分支、循环、并行节点？
- 流式输出如何端到端传递？
- 如何处理 Agent 执行中的暂停/恢复？

**模型网关**：
- 统一抽象层：不同模型的 Tool Calling 格式差异如何处理？
- 路由策略：成本 / 延迟 / 能力 三维路由
- 限流与降级：单用户 QPS 限制 / 模型故障自动切换

#### 2.4 技术权衡（10min）
- 为什么用 LangGraph 而不是自研引擎？
- 为什么用 MCP 协议而不是自定义 Plugin 协议？
- 多租户隔离：进程隔离 vs 容器隔离 vs 逻辑隔离？

#### 3.3 架构设计（30min）
