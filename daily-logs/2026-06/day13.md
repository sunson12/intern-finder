### 2. 记忆系统三层架构（30min）
```
┌─────────────────────────────────────┐
│           短期记忆（Working Memory）  │
│  当前对话的上下文窗口 + 滑动窗口      │
│  生命周期：单次会话                   │
├─────────────────────────────────────┤
│           长期记忆（Long-term Memory）│
│  跨会话的用户偏好 / 事实 / 经验       │
│  生命周期：永久（向量化持久存储）      │
├─────────────────────────────────────┤
│           语义记忆（Semantic Memory） │
│  概念 / 知识 / 规则（类似 RAG 知识库） │
│  生命周期：按需更新                   │
└─────────────────────────────────────┘
```
