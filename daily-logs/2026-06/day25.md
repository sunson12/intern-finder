### 3. "为什么做 Agent" 故事线（20min）
**面试高频问题**："你为什么选择 AI Agent 方向？"

三个角度各准备 2 句话：
- **技术趋势**：LLM 从信息处理工具变为自主决策实体，Agent 是 AI 从 passive 到 proactive 的转折
- **研究兴趣**：结合你的博士方向（如 NLP/RL/知识图谱 → Agent）
- **实践驱动**：做了什么 Agent 项目，体会到了什么（具体例子）

### 4. 反问准备（20min）
准备 5 个高质量反问（体现你的技术深度和对团队的关注）：

1. **技术方向**：
   "团队目前在 Agent 探索中遇到的最大技术挑战是什么？"

2. **技术决策**：
   "团队在 Agent 框架选型上（如 LangGraph vs 自研）的考量是什么？"

3. **评估体系**：
   "团队如何评估一个 Agent 的质量？有哪些核心指标？"

4. **成长空间**：
   "如果我有机会加入，前 3 个月可能会负责哪类工作？"

5. **技术文化**：
   "团队在技术选型上，自由度有多大？比如是否鼓励尝试新的开源方案？"
